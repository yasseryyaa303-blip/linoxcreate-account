1. Create a new repository on GitHub and upload all files (`bot.py`, `requirements.txt`, `Procfile`, `README.md`).
2. Go to [Railway](https://railway.app), click **New Project** -> **Deploy from GitHub repo**.
3. Select your repository.
4. Go to **Variables** tab in Railway and ensure your bot token is set:
   - `BOT_TOKEN` = `8511216882:AAG5F3aTEn7JMlRENJTwD6E0JczmoJeNqq8`
5. Railway will automatically build and start your bot using the `Procfile`.
